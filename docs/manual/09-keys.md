# 9. Keys

Every screen has a shortcut panel on the right; this is the same list, collected.

## Everywhere

| keys | what |
|---|---|
| F1 F2 F3 F4 | Song, Pattern, Instrument, Sample |
| F5 / F6 / F7 / F8 | play from start / from cursor / the row once / stop |
| F9 | follow the playing row |
| F10 / F11 | Info / Config |
| Alt+B | show or hide the browser |
| Alt+Up / Alt+Down | tempo by 1 bpm (with Shift, by 10) |
| Alt+S | solo the lane |
| Ctrl+Alt+P | floating parameter panel |
| Ctrl+Alt+E | stream manager (load per lane) |
| Ctrl+Alt+M | meters (loudness, correlation, spectrum) |
| Ctrl+Alt+O | vectorscope |
| Ctrl+Alt+S | script tab |
| Shift+F1 | help for the selected node |
| Ctrl+Z | undo |
| Ctrl+Alt+B | this manual |
| Ctrl+Alt+H | help for the machine under the cursor |

## Pattern editor

| keys | what |
|---|---|
| Space / Ctrl+Space | write the live value and step down / for every parameter column |
| Left, Right | one character (Ctrl+Left, Right: next or previous column; Ctrl+Shift: next or previous lane) |
| Shift+arrows | select |
| Ctrl+C X V D | copy, cut, paste, copy below |
| Ctrl+Delete / Ctrl+Insert | gobble / push down |
| Ctrl+Alt+Up, Down | rotate |
| Ctrl+I | interpolate |
| Ctrl+R | randomize (Alt+R rolls again) |
| Ctrl+K | colour of the pattern under the cursor |
| Shift+1 | note off in every note column of the row |
| Alt+Enter | solo-edit this pattern |
| Alt+T | tint patterns |
| Alt+V | MIDI velocity on or off |

## Song

| keys | what |
|---|---|
| Ctrl+B, Ctrl+E | loop start, end |
| Ctrl+1 | note-off marker |
| Ctrl+G | give the placement its own copy |
| Ctrl+Enter | solo-edit the pattern under the cursor |
| Tab | pattern alone or whole song |
| G | merge the selected block |

## Instrument

| keys | what |
|---|---|
| double-click, `/` | add a node |
| Shift+drag | take a node out of its chain |
| Alt+drag | copy a node |
| Ctrl+X | remove the node |
