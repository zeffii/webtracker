# webtracker

Run `node serve.mjs`, open http://localhost:8080, press Start, then Play pattern.
Run `npm test` for the offline smoke test of the graph and nodes.

Milestone 1 gate: a tone changes live with no zipper noise.
Milestone 2 gate: a preset instrument (sampler, filter, delay, out) plays notes
from a hand-written pattern, and the filter and delay can be tweaked live.
