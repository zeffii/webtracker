Shortcuts

        

          
Click, Esc
click the grid to start; Esc goes to the arrangement (in solo-edit, Esc first goes back to the whole song)

          
Up / Down
move a row (in nugget mode, by the nugget step, on the same character)

          
Tab, Shift+Tab
next / previous lane (in solo-edit, Tab switches between the pattern alone and the song with the rest locked)

          
PgUp/PgDn, Home/End
16 rows; first / last row (of the pattern, in solo-edit)

          
Shift+arrows
select cells; Esc drops the selection

          
Ctrl+C, X, V, A
copy, cut, paste; select the whole lane. Ctrl+Z undoes, Ctrl+Y or Ctrl+Shift+Z redoes

          
Ctrl+B, Ctrl+E, Ctrl+L
start the loop at this row, end it with this row; Ctrl+L switches it off and on

          
Space
write the live value of the parameter under the cursor (the node setting, or what the song last set) into this cell, then move down a row; on notes, velocities and commands it does nothing

          
Enter
insert a pattern

          
Z–M, Q–P
play notes

          
[ ]
octave

          
1
note off

          
`
note cut

          
0–9, A–F
overwrite the character under the cursor (an empty cell fills with zeros)

          
Delete, Backspace, >
clear the cell

          
Ctrl+Delete
delete the selected cells and pull the rows below up (inside the pattern only)

          
Ctrl+Alt+P
floating parameters: a window with the cursor lane's exposed sliders, to move with the mouse or a MIDI knob while the song plays (also the params button in the status bar); drag its title to move it

          
Ctrl+Alt+R
run the song's script on this pattern (its selection, if there is one); Ctrl+Alt+S opens the Script tab

          
Ctrl+Shift+Delete
remove the pattern under the cursor from the arrangement (it stays in the list; Ctrl+Z brings it back)

          
Ctrl+Insert
push the rows below down from the cursor (inside the pattern only)

          
Ctrl+Alt+Up / Down
rotate the contents of the selected rows, column by column

          
Ctrl+K
colour of the pattern under the cursor: the next of 16, then back to automatic; Ctrl+Shift+K the previous one

          
Ctrl+R
randomize menu for the selection; Alt+R rolls again from the original, any other key accepts

          
\ or Insert
note preview on / off: with it on, typed notes sound while the key is held

          
Ctrl+D
copy the selection (or the cell) to the rows right below it, wherever the cursor is; again to copy it once more below that

          
Alt+S
solo the lane under the cursor (the others ring out and go quiet); again brings everyone back

          
Alt+Up / Down
song tempo up or down by 1 bpm; with Shift by 10

          
Ctrl+Shift+R
arm recording: a MIDI keyboard writes into the pattern under the playhead of the cursor lane, on the nearest tick, while the song plays

          
Shift+1
a note off in every note column of this row of this lane, then down a row

          
Alt+V
MIDI velocity sensitive or not

          
Alt+T
tint each pattern faintly in its own colour, to see where they begin and end; again to switch it off

          
Alt+Enter
solo-edit the pattern under the cursor (only it is shown, rows numbered from 0); again, or Esc, goes back to the whole song

          
Ctrl+G
give this placement its own copy of the pattern (clone and replace), so edits stop reaching the other places it is used; works in solo-edit too

          
F5 F6 F7 F8
play from the start (or the loop); play from the cursor; play just this row once; stop

          
F9
follow the song: the grid scrolls with the playing row (highlighted). Moving the caret to another row pauses the following; F9 follows again

          
Ctrl+Up/Down
transpose the notes in the selection by a semitone (Shift: an octave)

          
Ctrl+, / Ctrl+.
lower / raise every other value in the selection by one (Ctrl+< / Ctrl+>: a bigger step); commands keep their id

          
Left / Right
to the start of the previous / next column (Config: one character at a time instead; a held key jumps by column)

          
Ctrl+Left/Right
one character left or right inside the cell, to type into just that digit; after that plain Left/Right stay inside the cell (and Up/Down keep the position) until you step past its edge, which enters the next cell at its first character; Up and Down then move by the nugget step (Config, 1 row by default) on the same character

          
Ctrl+Shift+H
hide or show the empty columns of the lane the cursor is in (a column with no value at any row; the one under the cursor stays)

          
Ctrl+Space
the same for every parameter column of this row (not notes, velocities or commands)

          
Ctrl+I
interpolate along a curve: per column, the first and last filled cell of the selection are the ends and the filled cells between them get values by row position. The popup picks a shape, bends it, lays a wave on it, lets you draw your own or shape a bezier spline with draggable anchors and handles, and can include empty cells; Enter applies, Esc cancels

          
Ctrl + Plus / Ctrl + Minus, Ctrl + 0, Ctrl + wheel
zoom the pattern text: bigger, smaller, back to normal

        

        
Edits are heard on the next tick. Dimmed rows are past the end of the pattern.

      

  

  

    

    

      
Scripts write pattern data into the pattern under the cursor in the pattern editor (or its selection). They run in their own thread, only when you ask, and change nothing if they fail or take too long. Ctrl+Enter runs the selected code, or all of it; Ctrl+Alt+R in the pattern editor runs the whole script on the pattern there. Saved with the project.

Shortcuts

        

          
Tab, Shift+Tab
next / previous field

          
Left/Right, − +
change a value (Shift bigger, Ctrl bigger still)

          
digits, Enter
type a value

          
Piano keys
play the sample; [ ] change the octave

          
Space
play the root note

          
Esc
back to the list

          
L
load samples

          
K
keep: copy the sample under the cursor into a new normal sample (for a tap take that you want to keep)

          
Record button
record a sample from another tab (the browser asks you to pick one and tick "Also share tab audio"), from the whole screen's audio, or from an input device or loopback. Esc or Stop keeps the take

          
Delete
remove the sample

          
Shift+drag
select part of the display; drag across it to make a loop, drag a marker to move it, double-click to clear

          
Marker region
the narrow view right of the waveform shows 800 frames around the current marker, the red line is the marker

      
+ −
in the list: nudge the current slice marker one frame (Ctrl 100); < and > choose the previous and next marker. The current one is drawn heavier and marked > in the Slices list

          
Shift+E
auto-slice: a marker on every hit of the sample, or of the selection (markers inside it are replaced). Sensitivity and the shortest gap are in Config (Sample)

          
Shift+M, Shift+U
mark a slice at the selection start, unmark the nearest one. The Slices list shows each one's number and hex value; in a pattern, command 10 0000 starts a note at the first, 10 0001 at the second, and so on (10 FFFF gives the Off column back its say)

          
Alt+click, Alt+drag
on the display: add a slice marker, move one. Alt+double-click removes the nearest

          
Shift+Z, Shift+A, Shift+W
zoom the display to the selection, out one step, to the whole sample. Ctrl+wheel zooms about the mouse; the wheel, or dragging with the middle button, moves along a zoomed view

          
Shift+C / T
trim

          
Shift+X
cut

          
Shift+S
silence

          
Shift+R
reverse

          
Shift+N
normalise

          
Shift+I / O
fade in / out

          
Shift+D
remove DC

          
Shift+B
bake the loop crossfade

          
Ctrl+B, Ctrl+E
start the loop at this tick, end it with this tick (again on the same tick to take it away); Ctrl+L switches the loop off and on

          
Ctrl+Z, Ctrl+Y
undo, redo

        

        
Edits apply to the selection, or to the whole sample when nothing is selected. Stereo samples stay stereo. The display shows the chosen sample as Waveform or Spectrum, with the loop between markers A and B and the sustain loop between a and b.

Shortcuts

        

          
Up/Down
in the list: choose an instrument

          
Enter
go to the graph

          
Esc
back to the list

          
Tab, Alt+arrows
in the graph: move between nodes

          
Insert
the machine menu: add a node

          
Ctrl+D
duplicate the selected node; Ctrl+X or Delete removes it

          
Up/Down
with a node selected: choose a parameter in its panel (PageUp/PageDown 8 rows)

          
Left/Right
change the parameter (Shift bigger, Ctrl smaller); Home/End go to the ends

          
Enter
menu for the parameter: type a value, reset, expose as a pattern column and its width, add a port (right-click a row does the same)

          
Ctrl+Alt+M
the meter band along the bottom: spectrum, level and loudness (LUFS), correlation, stereo width by band, spectrogram; which panels and how tall in Config

          
Ctrl+Alt+O
the vectorscope overlay: left against right, over any screen; drag it anywhere, drag its corner to resize, double-click to send it back to its corner; look and defaults in Config

          
F1, ?
with a node selected: its help page (what it is for, how to get the most out of it, its limits)

          
Piano keys
with a generator node (oscillator, sampler, synth) selected: play the instrument; [ ] change the octave

          
Delete, Ctrl+X
remove the node or wire

          
Shift+drag a node
take it out of its chain (its neighbours are joined) and move it

          
Alt+drag a node
make a copy and move the copy

          
Drag node
move it (a lassoed group moves together)

          
Drag empty space
lasso nodes; Shift+click adds one; Delete removes the group

          
Eye above a node
show a scope of what it puts out, beside it: click wave / spec / xy in its header to change the view, and 200 / 400 for the size

          
Middle button drag
pan the whole graph

          
Drag dot
from an output dot (right) to an input dot (left) to wire them

          
Right-click a node
replace it with another type from the same menu (sources and effects are not swapped for each other, so those rows are greyed): it keeps its place, its wires (to the ports of the same name, else the same position) and the parameters the two share

          
Right-click, double-click
empty space in the graph: insert a node. In the menu: the underlined letter of a row opens or inserts it, arrows and Enter move and open, Left or Esc go up a level, / (or clicking the box) searches: type, then Up/Down and Enter

          
Left/Right
on a slider: change the parameter (Shift for more)

        

        
An input can take several wires, which are added together; use a mix node when you want a ratio. Blue wires carry audio, amber wires control signals (envelopes, lfos, triggers), light red wires a ctrl node's glide into a parameter port (tick "port" beside a parameter to give it one), heavier purple wires a stereo pair (a mono wire into a stereo input feeds both channels; stereo into a mono input is averaged). "expose" adds a parameter to the instrument's pattern columns. Changing the wiring or the exposed list swaps the instrument in live and clears undo.

Shortcuts

        

          
Up/Down
move in time

          
Left/Right
change lane

          
Ctrl+wheel
the size of a row: a bar, half a bar, a beat (zoom in and out)

          
PgUp/PgDn
16 ticks

          
Enter
open the pattern under the cursor in the grid, or insert a new one

          
Ctrl+Enter
open the pattern under the cursor on its own (solo-edit): nothing else can be edited or pasted into. In the grid, Tab switches between showing only the pattern (rows from 0) and showing the whole song with the rest greyed, hatched and locked; Esc leaves it

          
I
insert a new pattern on top

          
two hex digits
place that pattern (see the list) and jump to its end

          
H
show or hide the pattern names in the cells

          
V
show or hide the pattern minimaps (small pictures of the notes in each cell)

          
N
clone

          
S
slice at the cursor

          
Alt+S
solo this lane: the other lanes let go of their notes (they ring out) and play nothing, shown darker; again to bring everyone back (also in the pattern editor)

          
G
with a block selected: merge everything inside it into one new pattern in each lane; patterns crossing the block's top or bottom are cut there; a lane with nothing in the block gets an empty pattern the size of the block

          
+ −
change length by 16

          
, .
move up or down a tick (< > sixteen)

          
Delete
remove the pattern; on an empty spot, pull up the patterns below (16 ticks, or as far as the gap)

          
Insert
push the patterns from here down 16 ticks

          
Shift+arrows, drag
select a block of lanes and rows

          
Ctrl+C, X, V
copy or cut the selected patterns (or the one under the cursor); paste with their top left at the cursor, over what is there

          
Ctrl+D
copy the selection to the rows right below it, wherever the cursor is; again to copy it once more below that

          
F5 F6 F7 F8
play from the start (or the loop); play from the cursor; play just this row once; stop

          
F9
follow the song: the rows scroll with the playing row (highlighted). Moving the caret to another row pauses the following; F9 follows again

          
Ctrl+Z, Ctrl+Y
undo, redo

          
O, Ctrl+1
put a note-off marker on this row (again to remove it): the lane lets go of what is sounding there, for patterns that end without a note off

          
Ctrl+B, Ctrl+E
start the loop at this row, end it at the start of this row, so this row is the first one after the loop (again on the same row to take it away); play starts at the loop and repeats it. L (or Ctrl+L) switches the loop off and on, keeping its points

          
Click a tick number
puts the playhead on that tick (the row's height is its ticks): while playing it jumps there, stopped it plays from there

          
Double-click a pattern
open it in the pattern editor (Ctrl+double-click: solo-edit)

          
W, Shift+W
set a waypoint, restore it

          
M
mute the lane from this row until the next M further down (shown dimmed, with <mute> and <play> cells marking the changes)

          
Shift+M
silence the whole lane, whatever its marks say; again to bring it back

          
K, Shift+K
step the colour of the pattern under the cursor through 16 pastels and back to automatic (Shift goes backwards)
